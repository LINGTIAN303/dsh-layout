# 布局插件：首版计划

## 目标

做一个只调整界面、不产出内容的 DSH 插件（bundle 名 `dsh-layout`），入口在插件详情页内，让左栏、右栏、会话区、设置页的结构、顺序、宽度、显隐可调。

## 验收标准

1. 插件管理器可安装并在「已安装插件」出现「布局」卡片，图标与中英文标题/描述正常。
2. 打开插件详情页可见内嵌「布局」编辑区，且只在 `dsh-layout` 自己的页面出现。
3. 「启用自定义布局」后：三栏顺序可换、宽度可改、左右栏可隐藏；侧栏五块与面板图标可排序/隐藏；会话内容宽度可调；设置面板宽高、导航宽、偏移可调。
4. 编辑模式可在界面上拖动列分隔条改宽度，并可用浮动工具条切换预设。
5. 关闭开关后界面立即回到宿主默认，不残留覆盖样式。
6. 刷新后配置保留；导出/导入 JSON 可用；恢复默认可用。
7. 不破坏宿主原有交互：导航、会话、右栏开关、快捷键、其它插件插槽正常。

## 第二轮：不可恢复状态审计（2026-11-08）

以「用户设置后是否可能再也回不来」为唯一检查项逐条排查：

| 场景 | 排查结论 | 处理 |
| --- | --- | --- |
| 隐藏左侧栏 | 唯一入口是左栏「插件」面板，隐藏后进不了插件详情页 → 不可恢复 | 常驻恢复按钮 + 快捷键 + 哈希重置 |
| 隐藏「插件」面板图标 | 同上 | 风险判定纳入面板隐藏 |
| 隐藏全部侧栏区块 | 侧栏没有可点内容，入口消失 | 风险判定纳入全部区块隐藏 |
| 列序/最小宽把侧栏挤出屏幕 | 实测侧栏盒子完全在视口外 | 风险判定实时测量侧栏与面板行可见性 |
| 设置面板偏移过大 | 面板会被推到屏幕外，关闭按钮不可见 | 应用时夹取偏移，保证面板完整留在屏幕内 |
| 窄屏/侧栏折叠态 | 覆盖规则与宿主折叠布局错位（实测侧栏被排到 0 号轨道） | 列序/宽度/隐藏规则加 `:not([data-sidebar-collapsed])` 门控，折叠态交还宿主 |
| 恢复浮层自身异常 | 工具条由组件渲染，异常时可能不出现 | 独立键盘监听直接恢复默认；Web 地址栏哈希兜底 |

已验证：隐藏侧栏刷新后出现「布局」恢复按钮 → 打开工具条 → 恢复默认成功；隐藏插件面板、隐藏全部区块、侧栏被挤出屏幕均触发恢复按钮；`Ctrl+Alt+L` 打开编辑浮层、`Ctrl+Alt+Shift+L` 直接恢复；`#dsh-layout=reset` 生效；极端偏移被夹取后设置面板完整可见；902px 窄窗口折叠态不再出现错误列序。

## 说明

- v1 只覆盖宽度 ≥768px 的三栏几何；窄屏抽屉、侧栏折叠态沿用宿主默认。
- 配置存客户端 `localStorage`；跨端同步用导出/导入。
