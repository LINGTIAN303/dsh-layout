# 布局插件：首版计划

## 目标

做一个只调整界面、不产出内容的 DSH 插件（bundle 名 `dsh-layout`），入口在插件详情页内，让左栏、右栏、会话区、设置页的结构、顺序、宽度、显隐可调。

## 验收标准

1. 插件管理器可安装并在「已安装插件」出现「布局」卡片，图标与中英文标题/描述正常。
2. 打开插件详情页可见内嵌「布局」编辑区，且只在 `dsh-layout` 自己的页面出现。
3. 「启用自定义布局」后：三栏顺序可换、宽度可改、左右栏可隐藏；侧栏五块与面板图标可排序/隐藏；会话内容宽度可调；设置面板宽高、导航宽、偏移可调。
4. 编辑模式可在界面上拖动列分隔条改宽度，并可用浮动工具条切换预设。
5. 关闭开关后界面立即回到宿主默认，不残留覆盖样式。
6. 刷新后配置保留；导出/导入 JSON 可用；恢复默认可用。
7. 不破坏宿主原有交互：导航、会话、右栏开关、快捷键、其它插件插槽正常。

## 实施步骤

- [x] 调研宿主外壳结构与插槽（Slot 树、AppFrame、侧栏、右栏、会话、设置面板 DOM）

- [x] 编写 Client 插件：配置模型、注解器、样式引擎、编辑区、编辑浮层、预设

- [x] 在真实 Web 客户端验证：结构识别、启用/关闭、排序、宽度、设置页几何、右栏宽度与位置、编辑模式、重置
- [x] 第二轮：不可恢复状态审计与多层恢复通道（恢复按钮、快捷键、哈希重置、偏移夹取）

## 第二轮：不可恢复状态审计（2026-11-08）

以「用户设置后是否可能再也回不来」为唯一检查项逐条排查：

| 场景 | 排查结论 | 处理 |
| --- | --- | --- |
| 隐藏左侧栏 | 唯一入口是左栏「插件」面板，隐藏后进不了插件详情页 → 不可恢复 | 常驻恢复按钮 + 快捷键 + 哈希重置 |
| 隐藏「插件」面板图标 | 同上 | 风险判定纳入面板隐藏 |
| 隐藏全部侧栏区块 | 侧栏没有可点内容，入口消失 | 风险判定纳入全部区块隐藏 |
| 列序/最小宽把侧栏挤出屏幕 | 实测侧栏盒子完全在视口外 | 风险判定实时测量侧栏与面板行可见性 |
| 设置面板偏移过大 | 面板会被推到屏幕外，关闭按钮不可见 | 应用时夹取偏移，保证面板完整留在屏幕内 |
| 窄屏/侧栏折叠态 | 覆盖规则与宿主折叠布局错位（实测侧栏被排到 0 号轨道） | 列序/宽度/隐藏规则加 `:not([data-sidebar-collapsed])` 门控，折叠态交还宿主 |
| 恢复浮层自身异常 | 工具条由组件渲染，异常时可能不出现 | 独立键盘监听直接恢复默认；Web 地址栏哈希兜底 |

已验证：隐藏侧栏刷新后出现「布局」恢复按钮 → 打开工具条 → 恢复默认成功；隐藏插件面板、隐藏全部区块、侧栏被挤出屏幕均触发恢复按钮；`Ctrl+Alt+L` 打开编辑浮层、`Ctrl+Alt+Shift+L` 直接恢复；`#dsh-layout=reset` 生效；极端偏移被夹取后设置面板完整可见；902px 窄窗口折叠态不再出现错误列序。

## 第三轮：恢复按钮点击修复（2026-11-08）

用户反馈：恢复按钮看不见可点效果（web 点击正常、桌面端无法点击）。

- 根因：浮层根 `.dshl-editLayer` 为 `pointer-events:none`，工具栏显式声明了 `auto`，恢复按钮漏了，实测按钮计算值 `none`、`elementFromPoint` 落到下层会话内容。
- 修复：按钮显式 `pointer-events:auto` + 内联 style；再加 document 捕获阶段 `pointerdown/mousedown` 坐标命中兜底；模块热更新时清理上一代样式标签，避免旧规则覆盖新规则。
- 验证：真实 CDP 鼠标点击可打开工具条；强制 `pointer-events:none` 后真实点击仍能通过坐标兜底打开；Esc 关闭、恢复默认正常。
- 待确认：桌面端窗口需刷新一次以加载新客户端模块后再复测。

## 第四轮：恢复按钮的落点策略（2026-11-08）

需求：允许把全部可见界面关掉（仅剩空白页）；空白页时按钮出现在页面中央作为键盘失灵时的最后兜底；平时按钮随机落在某个区域的留白处，不再固定占位。

- 新增「隐藏会话区」开关（`columns.hideCenter`），三栏可全部隐藏，形成空白页。
- 落点引擎：候选网格 → `elementFromPoint` 九点采样排除可交互元素 → 四方向留白评分 → 在最优一批里按种子随机；种子含配置指纹与本次加载随机盐。
- 三种模式：`free`（随机留白）、`blank`（屏幕正中，大号「恢复默认」+「编辑模式」+ 快捷键提示）、`corner`（探测失败退回左下角）。
- 首帧后延迟复探（320ms 起，最多 3 次），避免落在随后被内容覆盖的位置。
- 坐标命中兜底同步支持空白模式的按钮语义（`data-action`）。

已验证：只剩会话区时按钮落在会话区留白处（逐点扫描按钮矩形，压住可交互元素 0 处）；三栏全隐时进入空白模式，按钮组精确居中（中心 552,355 = 视口中心）；空白页「恢复默认」恢复全部栏位、「编辑模式」进入浮层而不改配置；同一会话内落点稳定，刷新后换位置。

## 第五轮：空白页恢复入口按钮组（2026-11-08）

需求：空白页时不要只给「恢复默认 / 编辑模式」，把「插件页」也并排放上去，而不是替换掉某一枚。

- 空白模式改为三枚并列按钮：恢复默认 / 插件页 / 编辑模式。
- 「插件页」先释放 `hideCenter` 再切面板，否则插件详情页所在的 `main` 面板仍是隐藏的，切过去照样空白；侧栏仍隐藏也不影响（面板切换走 `ctx.layout`，不依赖侧栏点击）。
- 空白页进入编辑模式时工具栏提示「当前没有可见区域可拖拽」，说明为什么没有框和手柄。
- 坐标命中兜底改为遍历所有 `[data-dshl-button]` 并直接 `click()`，三枚按钮共用一套兜底，不再需要按 `data-action` 分支。

已验证：空白页三枚按钮精确居中（中心 552,355 = 视口中心）；点「插件页」后 `hideCenter` 变 false、中栏 display:flex、main 面板显示插件页、入口切换为自由模式；点「编辑模式」进入浮层但不改配置（`enabled` 与 `hideCenter` 保持原值）；Esc 可退出。

补充（同轮）：自由落点的探测精度不够——稀疏 9 点采样会从采样间隙漏进底下的输入框，表现为按钮边角压住输入框。改为 7×5 网格 + 4px 外扩，并加「落位后自检」：300/900/1800/3200ms 各复检一次真实按钮矩形，压住就换种子重探（≤6 次）。多轮刷新验证：稳定后 5px 加密扫描的压住计数为 0。

## 第六轮：落点依附现有控件 + 通用性约束（2026-11-08）

用户反馈：随机落点过于随机，建议落点依附区域内现有控件（模型选择器旁、某插件控件旁），提升视觉和谐；并强调插件非原生，算法不能盯着现有插件写，要能兼容大部分第三方插件。

- **通用性约束**：落点算法不匹配任何类名 / `data-slot` / 框架特征，只用浏览器通用事实（元素矩形、可见性、`INTERACTIVE_SELECTOR` 这组 W3C/ARIA 通用可交互标记）。已用 grep 验证源码里没有宿主或第三方插件的具体类名。
- **测量范围扩到整页**：`surveyPage` 遍历 `document.body`，而不是四个列区域——插件可以渲染到 overlay、portal、body 直下，只扫列区域会看不见它们。
- **碰撞检测改矩形相交**：替换 `elementFromPoint` 点采样（会从药丸圆角与窄缝漏过），一次遍历精确判定。
- **依附优先**：同排按中心 y 分组（不看父容器，跨插件同排控件也能归到一起）；依附点必须落在该排跨度内（否则会飘到工具栏外，第一版实测就踩到）；两侧都有控件的「缝」得分最高。
- **遮挡守卫**：新增 MutationObserver，DOM 变化 600ms 后复查按钮是否被压住，是则递增 `reposition` 重算落点（1200ms 防抖）。

已验证：依附落在表情包按钮与模型选择器之间的空档，全页矩形重叠 0 处；注入第三方风格悬浮控件覆盖按钮后，约 2 秒内按钮自行改落点（附着到「分支」按钮旁），重叠消失；空白页三枚按钮仍精确居中。
